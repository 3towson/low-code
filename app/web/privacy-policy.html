นโยบายความเป็นส่วนตัว (Privacy Policy)

COD Customer Check (COD Risk Shield) · มีผลบังคับใช้: 13 ตุลาคม 2026

แอปพลิเคชัน COD Customer Check ("เรา", "ผู้ให้บริการ") ให้ความสำคัญอย่างยิ่งต่อการคุ้มครองข้อมูลส่วนบุคคลของผู้ใช้งาน ตามพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 (PDPA) รวมถึงหลักเกณฑ์ของ Apple App Store และ Google Play Store เอกสารนี้จัดทำขึ้นเพื่ออธิบายประเภทของข้อมูลที่เรารวบรวม วัตถุประสงค์ การประมวลผล ระยะเวลาการจัดเก็บ และสิทธิของเจ้าของข้อมูล

1. ข้อมูลส่วนบุคคลที่เราจัดเก็บ

เราเก็บรวบรวมข้อมูลส่วนบุคคลเท่าที่จำเป็นต่อการให้บริการ ดังนี้:

  • ข้อมูลบัญชีร้านค้า (Merchant Profile): ที่อยู่อีเมล, รหัสผ่าน (เก็บในรูปแบบเข้ารหัสทางเดียว Secure Hash โดยระบบ Supabase Auth), ชื่อร้านค้า
  • ข้อมูลการยืนยันตัวตนร้านค้า (Merchant KYC): ลิงก์ร้านค้า (Shop URL), หมวดหมู่สินค้า, เบอร์โทรศัพท์สำหรับติดต่อร้านค้า, ภาพถ่ายหลักฐานการมีตัวตนจริงของร้านค้า
  • ข้อมูลการรายงานลูกค้า COD ที่มีปัญหา:
    • หมายเลขโทรศัพท์ลูกค้า: เราไม่เก็บหมายเลขโทรศัพท์จริงของลูกค้าลงในฐานข้อมูล แต่จะแปลงเป็นค่าแฮชด้วยอัลกอริทึม SHA-256 ผสม Salt ความปลอดภัยสูง (phone_hash) บน Edge Function ทันที
    • ชื่อลูกค้า: สำหรับเป็นข้อมูลอ้างอิงเบื้องต้นในการตรวจสอบ
    • ข้อมูลเหตุการณ์: แพลตฟอร์มที่เกิดเหตุ, เหตุผลในการรายงาน (เช่น ปฏิเสธการรับพัสดุ, ติดต่อไม่ได้, ที่อยู่ปลอม), มูลค่าความเสียหาย, รายละเอียดเพิ่มเติม
    • ภาพหลักฐาน: ภาพถ่ายหน้าจอการสั่งซื้อหรือแชตการปฏิเสธพัสดุ (เก็บในระบบจัดเก็บไฟล์แบบส่วนตัว Private Storage)

2. การประมวลผลข้อมูลด้วยปัญญาประดิษฐ์ (Google Gemini AI)

การส่งข้อมูลไปยัง Google Gemini API

ในฟีเจอร์ "ตรวจด้วยข้อความออเดอร์" เมื่อผู้ใช้วางข้อความออเดอร์หรือแชต ข้อความดังกล่าวจะถูกส่งไปยัง Google Gemini API (Gemini 3.1 Flash Lite) ผ่าน Edge Function ที่ปลอดภัย เพื่อให้ AI สกัดเฉพาะหมายเลขโทรศัพท์และชื่อลูกค้าออกจากข้อความออเดอร์โดยอัตโนมัติ

ข้อกำหนดด้านความปลอดภัย: ข้อมูลข้อความออเดอร์จะไม่ถูกบันทึกลงฐานข้อมูลของเรา และไม่ถูกนำไปใช้ฝึกฝนโมเดล AI ของ Google ตามเงื่อนไขการให้บริการของ Google Cloud API สำหรับองค์กร

3. วัตถุประสงค์ในการประมวลผลข้อมูล

  • เพื่อยืนยันตัวตนและป้องกันการรายงานข้อมูลเท็จโดยร้านค้าที่ไม่มีตัวตนจริง (Merchant KYC)
  • เพื่อคำนวณและประเมินระดับความเสี่ยงของพฤติกรรมการปฏิเสธพัสดุเก็บเงินปลายทาง (COD) ช่วยปกป้องผู้ประกอบการร้านค้าออนไลน์จากการทุจริต
  • เพื่อให้บริการระบบและรักษาความปลอดภัยของระบบฐานข้อมูล

4. ระยะเวลาในการเก็บรักษาข้อมูล (Data Retention)

  • การคำนวณระดับความเสี่ยง: ระบบจะนำรายงานที่ได้รับอนุมัติในช่วง 12 เดือนล่าสุด มาคำนวณระดับความเสี่ยง (เขียว/เหลือง/แดง) รายงานที่มีอายุเกิน 12 เดือนจะไม่ถูกนำมาคิดระดับความเสี่ยง
  • ข้อมูลบัญชีร้านค้าและภาพหลักฐาน: จะถูกจัดเก็บไว้ตราบเท่าที่บัญชีผู้ใช้ยังคงเปิดใช้งาน และจะถูกลบถาวรทันทีเมื่อผู้ใช้ดำเนินการ ลบบัญชีผู้ใช้ (Account Deletion)
  • รายงานความเสี่ยงหลังลบบัญชี: ข้อมูลรายงานความเสี่ยงจะถูกตัดความเชื่อมโยงกับบัญชีผู้รายงานอย่างถาวร (Anonymized) เพื่อประโยชน์สาธารณะในการเตือนภัยทุจริตอย่างต่อเนื่อง

5. สิทธิของเจ้าของข้อมูลส่วนบุคคล (Data Subject Rights)

ภายใต้กฎหมาย PDPA คุณมีสิทธิดังต่อไปนี้:

  1. สิทธิในการเข้าถึงและขอรับสำเนาข้อมูลส่วนบุคคล: สามารถตรวจสอบข้อมูลร้านค้าและประวัติในแอปพลิเคชันได้ตลอดเวลา
  2. สิทธิในการขอแก้ไขข้อมูล: สามารถแจ้งขอแก้ไขข้อมูลร้านค้าที่ไม่ถูกต้องให้เป็นปัจจุบันได้
  3. สิทธิในการขอลบข้อมูล (Right to Erasure): สามารถกด "ลบบัญชีผู้ใช้" ได้โดยตรงจากเมนูการตั้งค่าภายในแอป หรือผ่านหน้าเว็บ ขอลบบัญชีผู้ใช้
  4. สิทธิของลูกค้าปลายทางในการโต้แย้ง (Dispute): หากท่านเป็นลูกค้าปลายทางที่เชื่อว่าเบอร์โทรศัพท์ของท่านถูกรายงานโดยไม่ถูกต้อง สามารถติดต่อเราทางอีเมลเพื่อยื่นคำร้องขอตรวจสอบและปลดรายงานได้

6. ความปลอดภัยของข้อมูล (Security Measures)

เราใช้มาตรการทางเทคนิคและการบริหารจัดการที่เข้มงวดเพื่อรักษาความลับและความปลอดภัยของข้อมูล ได้แก่ การเข้ารหัสข้อมูลระหว่างรับส่ง (HTTPS/TLS), การแฮชเบอร์โทรศัพท์ (SHA-256 + Secret Salt) บน Edge Function เท่านั้น, การควบคุมสิทธิ์การเข้าถึงฐานข้อมูลระดับแถว (Row Level Security: RLS) และการจัดเก็บภาพหลักฐานใน Private Storage Buckets
