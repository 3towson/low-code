## 1. ข้อความว่าง
- [ ] กด "ตรวจสอบ" โดยไม่พิมพ์อะไร ต้องเห็น "กรุณาวางข้อความออเดอร์" และไม่มีวงกลมหมุน

## 2. เบอร์สาธิต 0800000001 (green)
- [ ] วางข้อความ (ทั้งก้อน หลายบรรทัด):

```
ชื่อ สมหญิง ทดสอบ
โทร 080-000-0001
ที่อยู่ 99/1 ถ.สุขุมวิท กรุงเทพฯ 10110
```

- [ ] กด "ตรวจสอบ" ระหว่างรอ ปุ่มกลายเป็นวงกลมหมุน กดซ้ำไม่ได้ และช่องข้อความถูกปิด
- [ ] ต้องเห็นการ์ด **สีเขียว** มีไอคอนเครื่องหมายถูก และข้อความ **"ความเสี่ยงต่ำ"**
- [ ] คำแนะนำ "ส่งได้ตามปกติ"
- [ ] "จำนวนรายงาน: 0 รายงาน"
- [ ] "ชื่อลูกค้า: สมหญิง ทดสอบ" (ถ้า AI ใช้ไม่ได้ อาจเป็นชื่ออื่นหรือ "-" และต้องมีหมายเหตุตามข้อ 7)
- [ ] "เบอร์โทร: 080-XXX-0001" (ไม่แสดงเบอร์เต็ม)

## 3. เบอร์สาธิต 0800000002 (yellow)
- [ ] วางข้อความ `คุณสมชาย ใจดี 0800000002 บ้านเลขที่ 5 เชียงใหม่` แล้วกด "ตรวจสอบ"
- [ ] ต้องเห็นการ์ด **สีเหลือง** มีไอคอนเตือน และข้อความ **"ควรระวัง"**
- [ ] คำแนะนำ "ควรโทรหรือทักยืนยันออเดอร์กับลูกค้าก่อนแพ็กสินค้า"
- [ ] "จำนวนรายงาน: 1 รายงาน"
- [ ] "เบอร์โทร: 080-XXX-0002"
- [ ] **ไม่มี** ชื่อ "ลูกค้าสาธิต 2" (ชื่อที่ร้านอื่นกรอก) และไม่มีชื่อร้านที่รายงานแสดงที่ใดในหน้า

## 4. เบอร์สาธิต 0800000003 (red) เขียนเบอร์แบบ +66
- [ ] วางข้อความ `ส่งให้ วิชัย มีสุข เบอร์ +66 80 000 0003 ขอนแก่น` แล้วกด "ตรวจสอบ"
- [ ] ต้องเห็นการ์ด **สีแดง** มีไอคอนอันตราย และข้อความ **"ความเสี่ยงสูง"**
- [ ] คำแนะนำ "ไม่แนะนำให้ส่งแบบเก็บเงินปลายทาง ควรให้ลูกค้าโอนชำระก่อน"
- [ ] "จำนวนรายงาน: 2 รายงาน"
- [ ] "เบอร์โทร: 080-XXX-0003"

## 5. ข้อความที่ไม่มีเบอร์
- [ ] ล้างช่องแล้ววาง `ขอสั่งเสื้อ 2 ตัว ส่งที่ร้านกาแฟหน้าตลาด` แล้วกด "ตรวจสอบ"
- [ ] ต้องเห็น "ไม่พบเบอร์โทรในข้อความ กรุณากรอกเบอร์ลูกค้าเอง" พร้อมช่อง "เบอร์โทรลูกค้า" และปุ่ม "ตรวจสอบด้วยเบอร์"
- [ ] ไม่มีการ์ดสีแสดง
- [ ] กรอก `02-123-4567` แล้วกด "ตรวจสอบด้วยเบอร์" ต้องเห็น "เบอร์โทรไม่ถูกต้อง ต้องเป็นเบอร์มือถือไทย 10 หลัก" ใต้ช่อง (ไม่ส่งไป server)
- [ ] เปลี่ยนเป็น `๐๘๐-๐๐๐-๐๐๐๒` (เลขไทย) แล้วกด "ตรวจสอบด้วยเบอร์" ต้องเห็นการ์ดสีเหลือง "ควรระวัง" "จำนวนรายงาน: 1 รายงาน" "ชื่อลูกค้า: -" "เบอร์โทร: 080-XXX-0002"
- [ ] เปลี่ยนเป็น `0800000001` แล้วกด "ตรวจสอบด้วยเบอร์" ต้องเห็นการ์ดสีเขียว "ความเสี่ยงต่ำ"

## 6. ปิดอินเทอร์เน็ต
- [ ] วางข้อความในข้อ 3 อีกครั้ง
- [ ] ปิด Wi-Fi หรือถอดสายแลน แล้วกด "ตรวจสอบ"
- [ ] ภายในไม่เกินประมาณ 25 วินาที ต้องเห็นข้อความสีแดง "ไม่สามารถเชื่อมต่ออินเทอร์เน็ตได้ กรุณาตรวจสอบการเชื่อมต่อแล้วลองใหม่" และปุ่ม "ลองใหม่"
- [ ] แอปไม่ค้าง ไม่ปิดตัว ปุ่ม "ตรวจสอบ" กลับมากดได้ และข้อความที่วางไว้ยังอยู่
- [ ] กด "ลองใหม่" ขณะยังปิดเน็ต ต้องได้ข้อความเดิมอีกครั้ง (ไม่ค้าง)
- [ ] เปิดเน็ตคืน กด "ลองใหม่" ต้องเห็นการ์ดสีเหลือง "ควรระวัง" โดยไม่ต้องวางข้อความใหม่
- [ ] ทำซ้ำกับการตรวจด้วยเบอร์: ใช้ข้อความในข้อ 5 ให้ช่องเบอร์แสดง กรอก `0800000003` ปิดเน็ต กด "ตรวจสอบด้วยเบอร์" ต้องเห็นข้อความและปุ่ม "ลองใหม่" เปิดเน็ตแล้วกด "ลองใหม่" ต้องเห็นการ์ดสีแดง

## 7. (ไม่บังคับ) ระบบแยกชื่ออัตโนมัติไม่พร้อมใช้งาน
ทำเฉพาะเมื่อต้องการดูหมายเหตุ ai_unavailable: ตั้ง `GEMINI_MODEL` เป็นชื่อที่ไม่มีอยู่ชั่วคราว

```powershell
supabase secrets set GEMINI_MODEL=model-that-does-not-exist
```

- [ ] ตรวจข้อความในข้อ 3 ต้องยังได้การ์ดสีเหลือง "ควรระวัง" ตามปกติ และมีหมายเหตุตัวเล็ก "หมายเหตุ: ระบบแยกชื่ออัตโนมัติไม่พร้อมใช้งานในขณะนี้ ผลความเสี่ยงยังตรวจจากเบอร์โทรตามปกติ"
- [ ] ตั้ง `GEMINI_MODEL` กลับเป็นค่าเดิม (`supabase secrets set GEMINI_MODEL=<ชื่อโมเดลเดิม>`) แล้วตรวจอีกครั้ง หมายเหตุต้องหายไป
