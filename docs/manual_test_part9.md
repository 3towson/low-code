- [ ] มีบัญชีร้านที่ยืนยันอีเมลแล้ว (ใช้บัญชีจากส่วนที่ 8 ได้)
- [ ] รันแอปแบบเดียวกับส่วนที่ 8 (ไฟล์ `app/.env.flutter` ต้องมีแค่ `SUPABASE_URL` กับ `SUPABASE_ANON_KEY`)

```powershell
cd app
C:\flutter\bin\flutter.bat run -d windows --dart-define-from-file=.env.flutter
```

- [ ] login แล้วกด "รายงานลูกค้า" ที่หน้าหลัก ต้องเห็นหน้า "รายงานลูกค้า" ที่มีช่อง ชื่อลูกค้า, เบอร์โทร, แพลตฟอร์ม, เหตุผล, มูลค่าความเสียหาย และปุ่ม "ส่งรายงาน"
- [ ] dropdown แพลตฟอร์มแสดง Shopee, Lazada, Facebook, LINE, TikTok, อื่นๆ
- [ ] dropdown เหตุผลแสดง ปฏิเสธรับสินค้า, ติดต่อไม่ได้, ที่อยู่ปลอมหรือผิด, อื่นๆ

เบอร์ที่ใช้ทดสอบ: **080-000-9997** (ไม่ซ้ำกับเบอร์ใน test_part7 และ seed_demo)

SQL สำหรับดูผลใน Dashboard → SQL Editor (แทน `<อีเมลร้าน>` ด้วยอีเมลที่ login):

```sql
select id, left(phone_hash, 12) as hash_prefix, customer_name, platform, reason, amount, status, created_at
from cod_reports
where reported_by = (select id from auth.users where email = '<อีเมลร้าน>')
order by created_at desc
limit 5;
```

## 1. ตรวจฟอร์มก่อนส่ง (ไม่ต้องใช้เน็ต)
- [ ] กด "ส่งรายงาน" โดยไม่กรอกอะไร ต้องเห็น "กรุณากรอกชื่อลูกค้า", "กรุณากรอกเบอร์โทร", "กรุณาเลือกแพลตฟอร์ม", "กรุณาเลือกเหตุผล"
- [ ] ใส่เบอร์ `02-123-4567` ต้องเห็น "เบอร์โทรไม่ถูกต้อง ต้องเป็นเบอร์มือถือไทย 10 หลัก"
- [ ] ใส่มูลค่าความเสียหาย `2000000` ต้องเห็น "มูลค่าความเสียหายต้องเป็นตัวเลข 0 ถึง 1,000,000"
- [ ] ปล่อยมูลค่าความเสียหายว่างได้ ไม่มีข้อความเตือน

## 2. รายงานสำเร็จ
- [ ] กรอก ชื่อ `ทดสอบ ส่วนเก้า`, เบอร์ `080-000-9997`, แพลตฟอร์ม `Shopee`, เหตุผล `ปฏิเสธรับสินค้า`, มูลค่า `1,500`
- [ ] **กดปุ่ม "ส่งรายงาน" รัวๆ 3-5 ครั้ง**
- [ ] ระหว่างส่ง ปุ่มกลายเป็นวงกลมหมุน กดไม่ได้ และช่องกรอกถูกปิด
- [ ] ต้องเห็น "ส่งรายงานเรียบร้อยแล้ว ขอบคุณที่ช่วยแจ้งข้อมูล"
- [ ] ฟอร์มถูกล้าง: ทุกช่องว่าง dropdown กลับไปไม่มีค่า และไม่มีข้อความเตือนสีแดงค้าง
- [ ] รัน SQL ด้านบน ต้องพบรายงานใหม่ **1 แถวเท่านั้น** (กดรัวแต่ส่งครั้งเดียว) โดย
  - `platform` = `shopee`, `reason` = `refused_delivery` (เป็นค่า enum ไม่ใช่ภาษาไทย)
  - `amount` = 1500, `customer_name` = `ทดสอบ ส่วนเก้า`
  - `hash_prefix` เป็นตัวอักษร hex ไม่มีเลข 0800009997 ที่ไหนในแถว

## 3. รายงานซ้ำ
- [ ] กรอกข้อมูลเบอร์เดิม `0800009997` อีกครั้ง (รูปแบบต่างไปได้ เช่น `+66800009997`) เลือกแพลตฟอร์มและเหตุผลใดก็ได้ แล้วกดส่ง
- [ ] ต้องเห็นข้อความสีแดง "คุณรายงานเบอร์นี้ไปแล้วในช่วง 7 วันที่ผ่านมา"
- [ ] ฟอร์ม **ไม่** ถูกล้าง ข้อมูลที่กรอกยังอยู่ และปุ่มกดได้อีกครั้ง
- [ ] รัน SQL ด้านบน ยังมีรายงานเบอร์นี้แค่ 1 แถว

## 4. ปิดอินเทอร์เน็ตแล้วส่ง
- [ ] กรอกฟอร์มให้ถูกต้องด้วยเบอร์ใหม่ เช่น `080-000-9996`
- [ ] ปิด Wi-Fi หรือถอดสายแลน แล้วกด "ส่งรายงาน"
- [ ] ต้องเห็นข้อความสีแดง "ไม่สามารถเชื่อมต่ออินเทอร์เน็ตได้ กรุณาตรวจสอบการเชื่อมต่อแล้วลองใหม่" (ภายในไม่เกินประมาณ 20 วินาที)
- [ ] ฟอร์มไม่ถูกล้าง และปุ่มกลับมากดได้
- [ ] เปิดเน็ตคืน กด "ส่งรายงาน" อีกครั้งโดยไม่ต้องกรอกใหม่ ต้องเห็น "ส่งรายงานเรียบร้อยแล้ว ขอบคุณที่ช่วยแจ้งข้อมูล"

## 5. ล้างข้อมูลทดสอบ
รายงานที่สร้างในข้อ 2 และ 4 จะทำให้ส่งซ้ำไม่ได้ 7 วัน และมีผลกับการตรวจสอบลูกค้า ให้ลบเมื่อทดสอบเสร็จ (ลบเฉพาะแถวของร้านนี้ที่สร้างใน 1 ชั่วโมงที่ผ่านมา):

```sql
delete from cod_reports
where reported_by = (select id from auth.users where email = '<อีเมลร้าน>')
  and created_at > now() - interval '1 hour';
```

- [ ] รัน SQL ดูผลอีกครั้ง ต้องไม่เหลือแถวที่สร้างจากการทดสอบนี้
