# ส่วนที่ 8: Checklist ทดสอบระบบ login ด้วยมือ

## 0. เตรียมก่อนทดสอบ

### 0.1 ตั้งค่าใน Supabase Dashboard
- [ ] Authentication → Sign In / Providers → Email: เปิด **Confirm email**
- [ ] อีเมลที่ใช้สมัครต้องเป็นอีเมลของสมาชิกใน Supabase organization (SMTP ในตัวของ Supabase ส่งได้เฉพาะอีเมลเหล่านี้ ถ้าจะใช้อีเมลอื่นต้องตั้ง Custom SMTP)
- [ ] ถ้ามีผู้ใช้อีเมลนั้นอยู่แล้ว ให้ลบใน Authentication → Users ก่อน (แถวใน `sellers` ถูกลบตามด้วย cascade)
- หมายเหตุ: SMTP ในตัวจำกัดจำนวนอีเมลต่อชั่วโมงไว้ต่ำ ถ้าสมัครซ้ำหลายรอบจะเจอข้อความ "ทำรายการบ่อยเกินไป กรุณารอสักครู่แล้วลองใหม่"

### 0.2 ใส่ค่า config ของแอป
สร้างไฟล์ `app/.env.flutter` (ไฟล์นี้ถูก .gitignore ด้วยแพตเทิร์น `.env.*` อยู่แล้ว) ใส่แค่ 2 ค่านี้ **ห้ามใส่ service role key หรือ secret อื่น** เพราะค่าที่ส่งผ่าน dart-define จะถูกฝังลงในแอป

```
SUPABASE_URL=https://<project-ref>.supabase.co
SUPABASE_ANON_KEY=<anon key>
```

### 0.3 รันแอป (เลือกอย่างใดอย่างหนึ่ง)
ในเครื่องนี้ไม่มี Android emulator จึงใช้ Windows desktop หรือเว็บ

**ก. Windows desktop (แนะนำ)** ต้องเปิด Developer Mode ก่อนครั้งเดียว: รัน `start ms-settings:developers` แล้วเปิด Developer Mode

```powershell
cd app
C:\flutter\bin\flutter.bat run -d windows --dart-define-from-file=.env.flutter
```

**ข. เว็บ** ห้ามใช้ `-d chrome` ในการทดสอบข้อ 4 เพราะ `-d chrome` เปิด Chrome ด้วยโปรไฟล์ชั่วคราวทุกครั้ง session จะหายเอง ให้ใช้ web-server แบบกำหนด port แล้วเปิด http://localhost:8080 ใน Chrome ปกติ

```powershell
cd app
C:\flutter\bin\flutter.bat run -d web-server --web-port 8080 --dart-define-from-file=.env.flutter
```

ถ้าไม่อยากใช้ไฟล์ ส่งค่าตรง ๆ ได้แบบนี้:
```powershell
C:\flutter\bin\flutter.bat run -d windows --dart-define=SUPABASE_URL=https://<project-ref>.supabase.co --dart-define=SUPABASE_ANON_KEY=<anon key>
```

- [ ] รันโดยไม่ส่งค่า config ต้องเห็นข้อความ "ไม่พบค่า SUPABASE_URL หรือ SUPABASE_ANON_KEY"

## 1. สมัครใหม่แล้วได้อีเมล
- [ ] หน้า Login กด "ยังไม่มีบัญชี? สมัครสมาชิก"
- [ ] กด "สมัครสมาชิก" โดยไม่กรอกอะไร ต้องเห็นข้อความเตือนใต้ทุกช่อง
- [ ] ใส่รหัสผ่าน 7 ตัว ต้องเห็น "รหัสผ่านต้องมีอย่างน้อย 8 ตัวอักษร"
- [ ] ใส่ยืนยันรหัสผ่านไม่ตรงกัน ต้องเห็น "รหัสผ่านไม่ตรงกัน"
- [ ] กรอกชื่อร้าน (เช่น "ร้านทดสอบส่วน8"), อีเมล, รหัสผ่าน 8 ตัวขึ้นไปให้ถูกต้อง แล้วกดสมัคร
- [ ] ต้องเห็นกล่องข้อความ "กรุณายืนยันอีเมลก่อนเข้าสู่ระบบ" กด "ตกลง" แล้วกลับมาหน้า Login โดยช่องอีเมลกรอกไว้ให้แล้ว
- [ ] ได้รับอีเมลยืนยันจาก Supabase ในกล่องจดหมาย (ดูในโฟลเดอร์สแปมด้วย)
- [ ] Dashboard → Table Editor → `sellers` มีแถวใหม่ที่ `shop_name` ตรงกับชื่อร้านที่กรอก

## 2. Login ก่อนยืนยันอีเมลถูกปฏิเสธ
- [ ] **ยังไม่กดลิงก์ในอีเมล** กรอกอีเมลและรหัสผ่านที่เพิ่งสมัครแล้วกด "เข้าสู่ระบบ"
- [ ] ต้องเห็น "ยังไม่ได้ยืนยันอีเมล กรุณากดลิงก์ยืนยันในอีเมลก่อนเข้าสู่ระบบ" และยังอยู่หน้า Login
- [ ] กดลิงก์ยืนยันในอีเมล (หลังกดเบราว์เซอร์อาจพาไปหน้า Site URL ที่เปิดไม่ได้ เช่น localhost:3000 ถือว่าปกติ เพราะไม่ได้ทำ deep link อีเมลถูกยืนยันแล้ว)
- [ ] กลับมาที่แอป กด "เข้าสู่ระบบ" อีกครั้ง ต้องเข้าหน้า "หน้าหลัก"
- [ ] หน้าหลักแสดงชื่อร้านที่กรอกตอนสมัครถูกต้อง
- [ ] กด "ตรวจสอบลูกค้า" ต้องไปหน้าที่มีหัวข้อ "ตรวจสอบลูกค้า" กดย้อนกลับได้
- [ ] กด "รายงานลูกค้า" ต้องไปหน้าที่มีหัวข้อ "รายงานลูกค้า" กดย้อนกลับได้

## 3. รหัสผ่านผิด
- [ ] ออกจากระบบ (ถ้าอยู่ในระบบ) กรอกอีเมลที่ยืนยันแล้ว แต่รหัสผ่านผิด กด "เข้าสู่ระบบ"
- [ ] ต้องเห็น "อีเมลหรือรหัสผ่านไม่ถูกต้อง" และยังอยู่หน้า Login
- [ ] กรอกอีเมลที่ไม่มีในระบบ ต้องเห็นข้อความเดียวกัน (ไม่บอกว่ามีอีเมลนี้หรือไม่)

## 4. ปิดแล้วเปิดแอปยังอยู่ในระบบ
- [ ] login ให้อยู่หน้าหลัก
- [ ] Windows: ปิดหน้าต่างแอป (หรือกด `q` ในเทอร์มินัล flutter run) แล้วรันคำสั่ง flutter run เดิมอีกครั้ง
      เว็บ: ปิดแท็บ แล้วเปิด http://localhost:8080 ใหม่
- [ ] ต้องเข้าหน้าหลักทันทีโดยไม่ต้อง login และแสดงชื่อร้านถูกต้อง

## 5. Logout แล้วกลับหน้า Login
- [ ] ที่หน้าหลักกด "ออกจากระบบ" ต้องกลับไปหน้า Login ทันที
- [ ] ปิดแล้วเปิดแอปใหม่ ต้องยังอยู่หน้า Login (ไม่ถูก login อัตโนมัติ)

## 6. ไม่มีอินเทอร์เน็ต
- [ ] ปิด Wi-Fi หรือถอดสายแลน ที่หน้า Login กรอกอีเมลและรหัสผ่านแล้วกด "เข้าสู่ระบบ"
- [ ] ต้องเห็น "ไม่สามารถเชื่อมต่ออินเทอร์เน็ตได้ กรุณาตรวจสอบการเชื่อมต่อแล้วลองใหม่"
- [ ] เปิดเน็ตคืน แล้ว login ได้ตามปกติ
