| บทบาท | บัญชี | หน้าที่ใน e2e_test.ts |

เบอร์ที่ใช้ทดสอบ: **080-002-0011** (อยู่นอกช่วงเบอร์ของ seed_demo, test_part7, manual_test_part9 และ e2e_test.ts)

## 0. เตรียมก่อนทดสอบ
- [ ] Edge Function `check-customer` และ `report-customer` deploy แล้ว
- [ ] ถ้าไม่แน่ใจว่าบัญชี shop1/shop2 ยังอยู่ ให้รัน `deno run --allow-net --allow-read --allow-env scripts/seed_test.ts` (รันซ้ำได้)
- [ ] ตรวจว่าเบอร์ทดสอบยังไม่มีรายงานจากร้านทดสอบค้างอยู่ ใน Dashboard → SQL Editor:

```sql
select r.created_at, s.shop_name, r.status
from cod_reports r join sellers s on s.id = r.reported_by
where r.reported_by in (select id from auth.users where email in ('shop1@test.local', 'shop2@test.local'))
  and r.created_at > now() - interval '1 day'
order by r.created_at;
```

  ถ้ามีแถวค้างจากการทดสอบรอบก่อน ให้รัน SQL ในข้อ 5 ก่อน

## 1. B ตรวจเบอร์ → เขียว
- [ ] login ด้วย **B** (`shop2@test.local`)
- [ ] กด "ตรวจสอบลูกค้า" วางข้อความออเดอร์ แล้วกด "ตรวจสอบ"
- [ ] ต้องเห็นการ์ด **สีเขียว** "ความเสี่ยงต่ำ", "ส่งได้ตามปกติ", "จำนวนรายงาน: 0 รายงาน", "เบอร์โทร: 080-XXX-0011"
- [ ] กลับหน้าหลัก แล้วกด "ออกจากระบบ"

## 2. A รายงาน → B ตรวจ → เหลือง
- [ ] login ด้วย **A** (`shop1@test.local`)
- [ ] กด "รายงานลูกค้า" กรอก ชื่อ `ทดสอบ ส่วนสิบเอ็ด`, เบอร์ `080-002-0011`, แพลตฟอร์ม `Facebook`, เหตุผล `ปฏิเสธรับสินค้า` แล้วกด "ส่งรายงาน"
- [ ] ต้องเห็น "ส่งรายงานเรียบร้อยแล้ว ขอบคุณที่ช่วยแจ้งข้อมูล"
- [ ] ออกจากระบบ แล้ว login ด้วย **B**
- [ ] ตรวจด้วยข้อความออเดอร์เดิม ต้องเห็นการ์ด **สีเหลือง** "ควรระวัง", "ควรโทรหรือทักยืนยันออเดอร์กับลูกค้าก่อนแพ็กสินค้า", "จำนวนรายงาน: 1 รายงาน"
- [ ] ในการ์ด **ไม่มี** ชื่อร้าน "ร้านทดสอบ 1" หรืออีเมลของ A แสดงที่ใด
- [ ] ออกจากระบบ

## 5. ล้างข้อมูลทดสอบ
รายงานในข้อ 2 และ 4 จะทำให้เบอร์ทดสอบเป็นสีแดงไปอีก 90 วัน และทำให้ A/B รายงานเบอร์นี้ซ้ำไม่ได้ 7 วัน ให้ลบเมื่อเสร็จ
(รายงานใน seed_test และ seed_demo ย้อนหลังอย่างน้อย 10 วัน จึงไม่ถูกลบด้วยคำสั่งนี้):

```sql
delete from cod_reports
where reported_by in (select id from auth.users where email in ('shop1@test.local', 'shop2@test.local'))
  and created_at > now() - interval '1 day';
```

- [ ] รัน SQL ในข้อ 0 อีกครั้ง ต้องไม่มีแถว
- [ ] ตรวจเบอร์ `080-002-0011` ในแอปอีกครั้ง ต้องกลับเป็นการ์ดสีเขียว "ความเสี่ยงต่ำ"
